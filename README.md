# OmniOrder Engine

OmniOrder Engine is a high-throughput Java order processing, discount calculation, and wallet settlement engine.

## Features
- Dynamic customer tier discounting and promotional voucher calculation.
- Thread-safe inventory reservation and stock management.
- Multi-threaded batch order execution and transaction verification.
- In-memory session token caching and audit log export.

## Requirements
- Java 21+
- Apache Maven 3.8+

## Build and Test
```bash
mvn clean test
```
